# 功能矩阵

**状态：** Draft baseline · **版本：** 0.1.0

| 功能域 | Alpha 0.1 | Alpha 0.2 | Beta 0.5 | V1.0+ |
|---|---|---|---|---|
| Dashboard | 项目任务真实数据 | Agent 状态摘要 | 内容待办摘要 | 个性化工作洞察 |
| Personal Workspace | Workspace/Project/Task | 目标关联增强 | 日程与复盘增强 | 完整个人管理 |
| AI Workspace | 模块边界和状态模型 | Hermes/Agent Adapter 基础 | 更多适配器 | 多 Agent 协作 |
| Knowledge Workspace | 本地文件/附件管理；项目任务本地搜索；仅预留引用入口 | KnowledgeRef 模型、外部知识引用、Lingshu/Hindsight 连接器 | 关联与沉淀增强 | 高级知识组织 |
| Engineering Workspace | 项目入口和关联预留 | Git 信息集成 | 工程活动汇总 | DevOps 增强 |
| Creator Workspace | PRD/领域设计 | 内容模型预留 | 选题、草稿、版本、审核 | 内容运营闭环 |
| Automation Workspace | 不提供可视化编排 | 基础触发/任务模型 | 简单工作流 | 可视化与编排 |
| System & Security | 设置、审计、备份恢复；定义 Agent 权限边界但不开放 Agent 执行 | Agent Adapter 启用前完成授权、审批绑定和审计实现及验证 | 安全策略增强 | 高级治理 |

## 说明

1. 矩阵表示版本规划，不代表功能已经实现。
2. 微信公众号自动发布取决于官方接口权限和真实账号验证。
3. Agent 深度集成必须基于公开、稳定且可验证的接口。
4. 完全离线能力属于 Alpha 0.1 发布阻断要求。
5. 所有版本均需保留数据可导出、备份和迁移能力。
