# 产品需求文档（PRD）1.0

**产品：** 自磨工坊 · 个人智能工作台  
**英文描述：** Personal AI Workbench  
**状态：** Draft baseline，待 E0 评审冻结  
**版本：** 0.1.0  
**目标平台：** Windows、macOS

## 1. 产品概述
自磨工坊是一款本地优先的个人智能工作平台，统一组织个人目标、项目、任务、知识、AI Agent、工程活动和内容创作。它负责工作组织、上下文关联、任务协调、权限控制和结果追溯；专业工具负责专业执行。

## 2. 用户与核心场景
首要用户为需要管理复杂个人知识工作、软件工程项目和 AI 辅助任务的个人专业用户。关键场景：建立 Workspace；查看重点工作和阻塞事项；关联知识资料与工程项目；通过适配器连接外部 Agent 并追踪执行；管理微信公众号「AI智能体打磨工坊」的选题、文章和审核；断网时继续使用本地数据。

## 3. 功能需求

### 3.1 Dashboard
- 展示真实项目、任务、执行和系统状态。
- 支持从汇总项进入对应业务对象。
- 明确区分本地状态、远程连接状态和数据更新时间。
- 不显示无数据依据的虚构统计。

### 3.2 Personal Workspace
- 创建和切换 Workspace。
- 创建、编辑、归档和恢复 Project。
- 创建、编辑、完成和关联 Task。
- Task 可关联 Project；允许无项目任务。
- 记录创建、更新时间和必要的状态变更。

### 3.3 AI Workspace
- 定义与供应商无关的 Agent Adapter 契约。
- 展示适配器连接状态和能力声明。
- 记录 Agent 任务、执行状态、时间和结果引用。
- 对超时、取消、失败和不可用状态提供明确语义。
- 外部 Agent 断开不得影响本地项目和任务管理。
- 高风险操作必须经过权限检查和人工审批。

### 3.4 Knowledge Workspace
- 支持本地知识文件和外部知识资产引用。
- 保存来源、标识、标题、位置和可用状态等元数据。
- 外部知识服务不可用时保留引用记录并提示状态。
- 不未经授权复制、覆盖或删除外部知识库原始数据。

### 3.5 Engineering Workspace
- 项目可关联本地代码目录和 Git 仓库标识。
- 展示工程入口和必要元数据。
- 首期不替代 IDE、Git 客户端或 CI 平台。

### 3.6 Creator Workspace / Content Studio
目标公众号：**AI智能体打磨工坊**。内容生命周期：选题 → 研究素材 → 文章草稿 → 版本修订 → 审核 → 人工确认 → 发布/人工发布 → 运营记录。
- 管理选题状态、栏目、优先级和关联项目。
- 管理文章草稿、版本和附件。
- 保存内容来源、引用和 Evidence Status。
- 记录审核意见、审核人和时间。
- 发布记录关联目标账号、文章版本和失败原因。
- 运营指标记录采集来源和更新时间。
- 未经人工确认不得自动发布。
- 微信接口能力须经官方文档核对和真实账号验证；不支持自动发布时提供导出和人工发布路径。

### 3.7 Automation Workspace
首期支持记录自动化任务和执行状态；任务触发、权限、执行结果和错误应可追踪。可视化工作流编辑器和自主编排属于后续版本。

### 3.8 System & Security
展示数据目录和运行配置；保护敏感凭据；默认不开放公网监听；文件访问限制在用户授权目录；支持审计、备份、恢复和迁移状态检查。

## 4. 非功能需求
- Windows 和 macOS 均提供真实可安装构建。
- 首期核心业务数据以本地 SQLite 为权威数据源。
- 完全断网时核心工作管理仍可用。
- 数据库使用版本化 Migration。
- 数据库和附件备份可恢复并验证完整性。
- 关键操作可审计。
- Agent Adapter 可替换，不绑定单一 AI 厂商。
- 网络服务不可用时不得静默挂起或破坏本地数据。

## 5. 数据与隐私原则
本地数据默认留在本机。发送给外部 Agent 或服务的上下文必须经过明确配置和权限控制。连接器声明访问范围和能力。日志避免记录密钥、敏感正文和不必要的个人数据。备份位置由用户知情选择。

## 6. 版本范围
Alpha 0.1：本地工作台、项目任务、Dashboard、搜索、附件、备份恢复、审计、双平台离线验收。Alpha 0.2：Agent Adapter 基础和知识连接器。Beta 0.5：Content Studio 内容生产与审核基础流程。V1.0：各核心工作域形成可追踪协同闭环。

## 7. 发布阻断条件
任一平台无法安装或启动；离线核心流程失败；迁移或恢复导致数据丢失；存在未解决 P0 安全问题；Agent 可越权访问未授权资源；关键业务数据不持久化或 Dashboard 使用虚假数据。

## 8. 待评审事项
Workspace 多实例和目录策略、Task 字段与状态机、附件存储布局、macOS 最低版本、密钥管理实现、微信接口范围、Content Studio 版本归属和品牌商标核验。
