# 产品路线图

**状态：** Draft baseline · **版本：** 0.1.0

## E0 — 产品与架构基线
完成需求、架构、数据、安全、视觉和验收规范；通过评审后冻结 Alpha 0.1 范围。

## Alpha 0.1 — 可独立工作的本地个人工作台
Windows/macOS 桌面应用；Workspace、Project、Task；Dashboard、搜索和附件；SQLite Migration；审计、备份和恢复；完全离线验收。

## Alpha 0.2 — 可控的 Agent 与知识连接
统一 Agent Adapter 契约；Hermes 基础适配；Agent 执行记录、状态、取消和错误语义；KnowledgeRef；Lingshu/Hindsight 连接器评估与实现。

## Beta 0.5 — 内容生产工作台
微信公众号账号配置和状态；选题、研究素材、文章草稿和版本；事实来源和 Evidence Status；审核和发布辅助。微信官方接口经验证后再启用自动化发布能力。

## V1.0 — 个人智能工作系统
形成目标、项目、任务、Agent、知识和内容运营之间的可追踪闭环；具备可靠的权限、安全和恢复能力。

## V1.1+ — 服务端与多设备
评估独立 Web 服务、身份认证、同步协议和冲突解决。禁止多个客户端直接并发操作同一 SQLite 文件。

## V1.3+ — Agent 协作与工作流
增加多 Agent 协作、任务委派、可视化工作流和更完整的执行治理。

## 里程碑门禁

- Gate E0：PRD、需求追踪、架构和验收基线通过评审。
- Gate E1：双平台工程骨架可构建，基础通信和数据库初始化通过。
- Gate E2：本地业务闭环和离线场景通过。
- Gate E3：Agent/知识集成权限和失败降级通过。
- Gate E4：内容流程、审核和发布辅助通过。
- Gate E5：双平台安装、升级、恢复、安全和发布检查通过。

## 进度管理原则
路线图不预设未经验证的交付日期。每个里程碑应以可复现的验收证据关闭，不以代码行数、页面数量或演示截图代替验收。
