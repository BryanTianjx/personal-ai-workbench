# Architecture Decision Records

本目录记录影响产品边界、技术架构、数据、安全和集成方式的关键决策。

## 状态定义
- Proposed：提议中，尚未批准。
- Accepted：已批准并作为当前基线。
- Superseded：已被后续 ADR 替代。
- Deprecated：不再推荐，但保留历史记录。

## 记录规则
每份 ADR 至少包含背景、决策驱动因素、候选方案、决策、后果、风险、验证要求和状态。改变已接受的架构决策时，新增 ADR，不覆盖历史决策。
