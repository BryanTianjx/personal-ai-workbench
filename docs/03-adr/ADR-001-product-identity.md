# ADR-001：品牌、产品与仓库身份分离

- **状态：** Proposed
- **日期：** 2026-11-04
- **决策范围：** 品牌与项目身份

## 背景
项目需要同时具备易识别的中文品牌、清晰的产品描述、稳定的代码仓库标识和独立的内容传播渠道。将品牌名直接用作仓库名会使代码项目身份与未来品牌调整耦合。

## 决策驱动因素
- 中文用户对产品的识别和记忆。
- Git 仓库名称应清楚表达软件项目用途。
- 产品品牌、软件产品和微信公众号具有不同职责。
- 英文描述应准确传达产品类别，但不应在未核验前被视为商标。
- 品牌命名不应影响技术架构和数据结构。

## 候选方案
1. 所有对象统一使用同一名称。
2. 品牌、产品描述、仓库和内容渠道分别命名。
3. 将英文品牌名作为仓库名。

## 决策
采用方案 2：
| 对象 | 名称 |
|---|---|
| 母品牌/中文产品品牌 | 自磨工坊 |
| 产品描述 | Personal AI Workbench |
| Git 仓库 | personal-ai-workbench |
| 微信公众号 | AI智能体打磨工坊 |
| 英文品牌商标 | 暂不确定 |

## 后果
仓库名称表达清晰，且与品牌调整解耦；公众号可独立运营，同时与软件产品共享内容和项目上下文；英文描述作为产品类别说明，不承担商标职责。UI、README、发布物和内容渠道应遵守名称映射。不得将公众号名称误认为软件产品名称，不得将仓库名称当作注册品牌。

## 待验证事项
「自磨工坊」及相关类别的商标近似检索；域名、社交媒体账号和同名软件/开源项目检索；品牌视觉、字体和图形资产的授权情况。

## 变更规则
若品牌名称改变，更新本 ADR 或新增后续 ADR；除非产品定位也发生变化，不要求更改仓库名 `personal-ai-workbench`。
