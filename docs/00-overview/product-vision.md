# 产品愿景

**状态：** Draft baseline · **版本：** 0.1.0

## 愿景
帮助个人构建一套由自己掌控、可以持续改进的智能工作系统，将目标、项目、任务、知识、AI Agent、工程实践和内容创作组织在同一个可追溯的工作环境中。自磨工坊的重点不是聚合更多聊天窗口，而是把意图转化为行动，把行动转化为成果，再将成果和经验沉淀为可复用资产。

## 用户问题
个人工作常分散在项目管理工具、文档库、代码仓库、AI 助手、自动化脚本和内容平台中，导致目标与任务脱节、Agent 执行缺乏上下文、知识和决策依据难以追溯、工具间重复整理、网络不可用时基础工作中断，以及自动化权限边界不清。

## 目标用户与场景
首要用户是需要管理复杂知识工作、软件工程和 AI 辅助任务的个人专业用户。典型场景：拆解个人目标；查看项目和待办；委派任务给 Hermes、Codex 等 Agent；关联 Lingshu 知识；记录工程验证；管理微信公众号「AI智能体打磨工坊」选题和文章；断网时继续管理本地项目、任务和附件。

## 核心价值
- 统一组织：以工作对象和关系组织信息，而非以工具品牌组织信息。
- 持续积累：项目成果、知识引用、执行记录和内容资产可追溯。
- 可控智能：Agent 通过适配器、权限和审批边界参与工作。
- 离线韧性：核心本地工作不依赖云服务可用性。
- 渐进扩展：通过模块边界和连接器逐步增加能力。

## 核心工作闭环
目标 → 项目 → 任务 → 人或 Agent 执行 → 结果验证 → 知识与成果沉淀 → 复盘改进。Dashboard 围绕当前重点、下一步行动、阻塞事项和执行结果组织，而不是堆叠无行动价值的统计图表。

## 产品边界
自磨工坊是工作控制与组织平台，不重新实现 IDE 或 Agent Runtime，不替代 Lingshu 等知识库的原始文档存储，不将 Hindsight 作为唯一业务数据库；不在未经官方能力验证前承诺完整微信公众号自动发布，也不在首期构建多用户 SaaS 或微服务平台。

## 成功标准
Alpha 阶段成功意味着用户可在 Windows 和 macOS 桌面应用中离线创建和管理 Workspace、项目、任务，完成搜索、附件管理、备份恢复和审计；联网时逐步连接外部 Agent 和知识服务，且故障不会破坏本地核心工作。
