## 2. Requirement and architecture rules reaffirmed

- ADR-006 is the accepted topology decision: one local authoritative `app.sqlite` for Alpha 0.1 through V1.0; Workspace isolation is logical and enforced by backend policy.
- PostgreSQL is not a desktop runtime prerequisite and is not a synchronization protocol.
- Agent permissions are explicit independent capabilities: Read, Write, Execute and human-only Admin.
- High-risk approval confirms an action inside an existing grant; it cannot widen scope or grant a missing capability.
- Requests outside a grant are denied until the human owner explicitly changes the grant and the request is re-evaluated.
- System-prohibited actions remain denied regardless of approval.
- All architecture and implementation/verification status labels remain distinct. This documentation change does not claim any feature is implemented or tested.
