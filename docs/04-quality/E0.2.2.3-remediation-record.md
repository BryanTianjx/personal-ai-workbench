## 2. Validator contract

Run locally:

```bash
python3 scripts/validate-docs.py
```

Optional format repair:

```bash
python3 scripts/validate-docs.py --fix-format
```

The validator checks:

- Markdown terminal newlines, trailing whitespace, list spacing, fenced code blocks, heading-level jumps and table column consistency.
- Relative Markdown link targets.
- Formal requirement IDs in the requirements baseline and exact coverage in the architecture traceability matrix.
- ADR-001 through ADR-006 file presence, index links, implementation/verification status, risk and validation sections.
- README phase marker equals E0.2.2.3.

The script uses only the Python standard library. It does not claim to replace platform builds, security testing, or implementation acceptance.
